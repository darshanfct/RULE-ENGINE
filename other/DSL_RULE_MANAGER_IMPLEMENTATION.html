Purpose: Centralized DSL rule loading and management

Key Features:

  • ✅ Loads DSL rules using dsl_loader_v2::load_all()
  • ✅ Creates DslExecutorV2 instance
  • ✅ Handles hot reload if enabled
  • ✅ Provides shared executor via Arc<DslExecutorV2>
  • ✅ Manages lifecycle and statistics

Main API:

pub struct DslRuleManager {
    loaded_rules: Arc<RwLock<LoadedRules>>,
    executor: Arc<DslExecutorV2>,
    hot_reload_handle: Option<JoinHandle<()>>,
}

impl DslRuleManager {
    /// Initialize from AppConfig
    pub fn from_app_config(app_config: &AppConfig) -> Result<Self, LoaderError>
    
    /// Get DSL executor (shared across all components)
    pub fn executor(&self) -> Arc<DslExecutorV2>
    
    /// Get rule statistics
    pub fn stats(&self) -> LoadStats
}

Initialization Flow:

1. Load DSL rules from config.toml directories
2. Validate rules (circular dependencies, level hierarchy)
3. Build indexes (rules_by_id, rules_by_level)
4. Create DslExecutorV2 instance
5. Start hot reload watcher (if enabled)
6. Return manager with shared executor

🔄 END-TO-END FLOW

Startup Flow:

1. Load config.toml → AppConfig
2. Initialize DslRuleManager:
   ├─> Load DSL rules (dsl_loader_v2::load_all)
   ├─> Validate rules
   ├─> Build indexes
   ├─> Create DslExecutorV2
   └─> Start hot reload watcher (if enabled)
3. Get DSL executor from manager
4. Create SyslogProcessor with DSL executor
5. Start processing loop

Runtime Flow (per log):

1. Receive log from Redis stream
2. Decode & normalize (DecoderEngine)
3. Convert to JSON format (unified schema)
4. Evaluate with DSL executor (DslExecutorV2.evaluate)
5. Convert RuleMatch → Alert format
6. Generate alert IDs
7. Write to Redis stream

📊 KEY DIFFERENCES: JSON vs DSL

Aspect JSON Rules (OLD) DSL Rules (NEW)
File Format .json files .dsl files
Loader load_rules_from_directory() DslRuleManager
Parser serde_json dsl_parser_v2
Executor RuleEngine DslExecutorV2
Event Format Event struct (HashMap) serde_json::Value
Result Format Vec<Alert> Vec<RuleMatch>
Features Basic expressions 40+ operators, correlation, requires
Hot Reload ❌ Not supported ✅ Supported
Correlation ❌ Not supported ✅ Full support
Rule Dependencies ❌ Not supported ✅ Requires blocks
