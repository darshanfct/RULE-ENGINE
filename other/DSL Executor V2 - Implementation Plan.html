DSL Executor V2 - Implementation Plan

🎯 Overview

DSL Executor V2 is the runtime evaluation engine that processes events against loaded DSL rules. It replaces the current dsl_executor.rs with a production-grade implementation that supports:

  • Modern DSL AST from dsl_parser_v2.rs
  • Hot-reloadable rules from dsl_loader_v2.rs
  • All Expression operators (IP matching, port matching, time matching, list lookups, etc.)
  • Correlation & Aggregation (event counting, value counting, temporal sequences)
  • Parent-child hierarchy with requires block support
  • Level-based evaluation (evaluate level 0 → 1 → 2 → ...)

📊 Current State vs Target State

Current dsl_executor.rs Limitations

  1. Uses old parser structures (RuleDefinition, Expression from dsl_parser.rs)
  2. Limited operators - Only basic comparisons, no IP/port/time matching
  3. No list support - Cannot use @list_name lookups
  4. No correlation - No aggregation or temporal sequence support
  5. No requires block - Only simple parent_id checking
  6. No level-based evaluation - Rules evaluated randomly
  7. No hot reload - Rules loaded once at startup

DSL Executor V2 Goals

  1. ✅ Use DslRule from dsl_parser_v2.rs
  2. ✅ Support all 40+ Expression variants
  3. ✅ List lookups (string lists, IP/CIDR lists, port lists)
  4. ✅ Correlation engine (event_count, value_count, temporal sequences)
  5. ✅ requires block evaluation (parent dependencies)
  6. ✅ Level-based evaluation (process rules by level)
  7. ✅ Hot reload support (Arc<RwLock<LoadedRules>>)

🏗️ Architecture

Data Flow

Event (JSON) 
    ↓
DSL Executor V2
    ↓
    ├─→ Evaluate by Level (0 → 1 → 2 → ...)
    ├─→ Check requires block (parent dependencies)
    ├─→ Evaluate condition expression

Core Components

  1. DslExecutorV2 - Main executor struct
  2. ExpressionEvaluator - Evaluates all Expression variants
  3. ListLookup - Handles list lookups (@list_name)
  4. CorrelationEngine - Manages aggregation/temporal logic
  5. RequiresEvaluator - Checks parent dependencies
  6. RuleMatch - Result structure

/// Severity levels for alerts
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Serialize, Deserialize)]
pub enum Severity {
    Low = 1,
    Medium = 2,
    High = 3,
    Critical = 4,
}

impl Severity {
    /// Convert to numeric (1-10) for compatibility
    pub fn to_numeric(&self) -> u8 {
        match self {
            Severity::Low => 3,
            Severity::Medium => 6,
            Severity::High => 8,
            Severity::Critical => 10,
        }
    }
    
    /// Convert from numeric (1-10)
    pub fn from_numeric(n: u8) -> Self {
        match n {
            0..=2 => Severity::Low,
            3..=5 => Severity::Medium,
            6..=8 => Severity::High,
            9..=10 => Severity::Critical,
            _ => Severity::Medium,
        }
    }
}

/// Get severity from rule: Extract from groups first, fall back to level mapping
/// Based on real-world FortiGate rule analysis:
/// - Groups field contains actual severity (most accurate)
/// - Level represents hierarchy/complexity, not severity
/// - Level 1 rules can have critical groups!
impl DslRule {
    pub fn get_severity(&self) -> Severity {
        // Priority 1: Extract from groups (most accurate)
        if let Some(severity) = Self::extract_severity_from_groups(&self.groups) {
            return severity;
        }
        
        // Priority 2: Check noalert (informational rules)
        if self.no_email_alert || self.no_log {
            return Severity::Low;
        }
        
        // Priority 3: Level-based mapping (fallback)
        level_to_severity(self.level)
    }
    
    /// Extract severity from groups field
    fn extract_severity_from_groups(groups: &[String]) -> Option<Severity> {
        let mut found_severity: Option<Severity> = None;
        
        for group in groups {
            match group.to_lowercase().as_str() {
                "critical" => {
                    return Some(Severity::Critical); // Highest priority
                }
                "high" => {
                    if found_severity != Some(Severity::Critical) {
                        found_severity = Some(Severity::High);
                    }
                }
                "medium" => {
                    if found_severity.is_none() || found_severity == Some(Severity::Low) {
                        found_severity = Some(Severity::Medium);
                    }
                }
                "low" => {
                    if found_severity.is_none() {
                        found_severity = Some(Severity::Low);
                    }
                }
                _ => {}
            }
        }
        
        found_severity
    }
}

/// Fallback mapping: Level → Severity
/// Based on rule hierarchy/complexity, NOT actual threat level
/// Real-world analysis: Level 0=Low, Level 1=Medium, Level 2=Medium, Level 3=High, Level 4+=High/Critical
pub fn level_to_severity(level: u32) -> Severity {
    match level {
        0 => Severity::Low,        // Base detection (noalert=1, info)
        1 => Severity::Medium,     // Single-event detection (most common, 78.5% of rules)
        2 => Severity::Medium,     // Aggregation/correlation (17% of rules)
        3 => Severity::High,       // Advanced correlation (2.1% of rules)
        4..=6 => Severity::High,   // Multi-stage attacks (0.9% of rules)
        7..=15 => Severity::Critical, // Critical multi-stage
        _ => Severity::Medium,     // Default fallback
    }
}

/// Result of rule evaluation
pub struct RuleMatch {
    pub rule_id: String,
    pub rule_name: String,
    pub level: u32,
    pub severity: Severity,           // Extracted from groups (or level fallback)
    pub severity_numeric: u8,         // Numeric severity (1-10) for compatibility
    pub tags: Vec<String>,
    pub groups: Vec<String>,
    pub matched_fields: HashMap<String, String>, // Fields that matched
    pub timestamp: DateTime<Utc>,
}

impl RuleMatch {
    pub fn from_rule(rule: &DslRule) -> Self {
        let severity = rule.get_severity();
        
        Self {
            rule_id: rule.id.clone(),
            rule_name: rule.name.clone(),
            level: rule.level,
            severity,
            severity_numeric: severity.to_numeric(),
            tags: rule.groups.clone(),
            groups: rule.groups.clone(),
            matched_fields: HashMap::new(),
            timestamp: Utc::now(),
        }
    }
}

2. Expression Evaluation

All Expression variants to support:

Boolean Operations

  • And(Box<Expression>, Box<Expression>)
  • Or(Box<Expression>, Box<Expression>)
  • Not(Box<Expression>)

Field Matching

  • FieldEq(FieldRef, Value) - field["name"] == "value"
  • FieldNe(FieldRef, Value) - field["name"] != "value"
  • Contains(FieldRef, String) - field.contains("text")
  • Regex(FieldRef, String) - field.regex(r"\d+")
  • Pcre(FieldRef, String) - field.pcre(r"(?<=a)b")

IP/CIDR Matching

  • SrcIpIn(IpValue) - src_ip in 10.0.0.0/8
  • DstIpIn(IpValue) - dst_ip in 192.168.1.1

Port Matching

  • SrcPortEq(u16), SrcPortNe(u16), SrcPortGt(u16), etc.
  • DstPortEq(u16), DstPortNe(u16), DstPortGt(u16), etc.

Protocol Matching

  • ProtocolEq(String) - protocol == "tcp"
  • ProtocolNe(String)

User Matching

  • UserEq(String) - Expands to src_user == "admin" OR dst_user == "admin"
  • UserNe(String)

URL Matching

  • UrlContains(String), UrlEq(String), UrlNe(String)

Event ID Matching

  • EventIdEq(u64), EventIdNe(u64), EventIdGt(u64), etc.

Status Matching

  • StatusEq(String), StatusNe(String)

Hostname Matching (Unified: src_hostname)

  • HostnameEq(String), HostnameNe(String)

Process Name Matching (Unified: process_name)

  • ProcessNameEq(String), ProcessNameNe(String)

Action Matching

  • ActionEq(String), ActionNe(String)

Data Field Matching

  • DataContains(String), DataEq(String), DataNe(String)

Extra Data Matching

  • ExtraDataEq(String), ExtraDataNe(String)

Time Matching

  • TimeBetween(TimeRange) - time between(18:00, 07:00)

Weekday Matching

  • WeekdayIn(Vec<Weekday>) - day in [mon..fri]

Source Type Matching (Unified: source_type)

  • SourceTypeEq(String), SourceTypeNe(String)

Category Matching

  • CategoryEq(String), CategoryNe(String)

List Operators

  • InList(FieldRef, String) - src_ip in @blocked_ips
  • NotInList(FieldRef, String) - user not in @allowed_users
  • InCidrList(FieldRef, String) - ip in @internal_networks
  • ListMatchKeyValue(FieldRef, String, String) - lookup(@list, key) =~ r"val"

Rule Dependencies (for correlation)

  • CausedBySid(String) - caused_by(sid: 100)
  • CausedByGroup(String) - caused_by(group: "auth")
  • CausedByLevel(LevelCondition) - caused_by(level >= 10)
  • CausedByMatchedSid(String) - From aggregation buffer
  • CausedByMatchedGroup(String) - From aggregation buffer

Literals

  • True, False

FieldRef resolution:

  • field["name"] → Access event JSON at path ["name"]
  • data.aws.region → Access nested path ["data"]["aws"]["region"]
  • Unified field mapping (e.g., hostname → src_hostname)

4. List Lookup Implementation

fn evaluate_list_lookup(
    &self,
    field_ref: &FieldRef,
    list_name: &str,
    lists: &LoadedLists,
    event: &JsonValue,
) -> bool {
    // Get field value from event
    let field_value = self.get_field_value(field_ref, event)?;
    
    // Check string lists
    if let Some(list) = lists.lists.get(list_name) {
        return list.contains(&field_value.to_string());
    }
    
    // Check IP lists
    if let Some(ip_list) = lists.ip_lists.get(list_name) {
        if let Ok(ip) = field_value.to_string().parse::<std::net::IpAddr>() {
            return ip_list.iter().any(|network| network.contains(&ip));
        }
    }
    
    // Check port lists
    if let Some(port_list) = lists.port_lists.get(list_name) {
        if let Ok(port) = field_value.to_string().parse::<u16>() {
            return port_list.contains(&port);
        }
    }
    
    false
}

5. Requires Block Evaluation

fn evaluate_requires_block(
    &self,
    requires: &RequiresBlock,
    matched_rules: &MatchedRulesBuffer,
) -> bool {
    // Check if any requirement is satisfied
    for requirement in &requires.requirements {
        match requirement {
            Requirement::AnySid(sids) => {
                if sids.iter().any(|sid| matched_rules.has_sid(sid)) {
                    return true;
                }
            }
            Requirement::AnyGroup(groups) => {
                if groups.iter().any(|group| matched_rules.has_group(group)) {
                    return true;
                }
            }
            Requirement::AnyLevel(level_cond) => {
                if matched_rules.has_level(level_cond) {
                    return true;
                }
            }
            Requirement::AllOf(sub_reqs) => {
                // All sub-requirements must be satisfied
                if sub_reqs.iter().all(|req| self.evaluate_requirement(req, matched_rules)) {
                    return true;
                }
            }
        }
    }
    false
}

6. Correlation Engine

Correlation types:

Event Count

correlation {
  type = event_count
  count >= 5
  within 300s
  group_by = [src_ip]
}
  • Count events matching condition
  • Group by specified fields
  • Trigger when count threshold reached

Value Count

correlation {
  type = value_count
  field = dst_port
  unique_values >= 20
  within 60s
  group_by = [src_ip]
}
  • Count unique values of a field
  • Group by specified fields
  • Trigger when unique count threshold reached

Temporal Sequence

correlation {
  type = temporal
  sequence = [
    { sid: 100 },
    { sid: 101 },
    { sid: 102 }
  ]
  within 300s
}
  • Track sequence of rule matches
  • Trigger when sequence completes in order

Ordered Temporal Sequence

correlation {
  type = ordered_temporal
  sequence = [...]
  within 300s
}
  • Same as temporal but requires strict ordering

Correlation state management:

  • Store aggregation buffers per group_by key
  • Time-based expiration (sliding window)
  • Thread-safe access with Arc<RwLock<>>

7. Level-Based Evaluation

pub fn evaluate(&self, event: &JsonValue) -> Vec<RuleMatch> {
    let rules = self.loaded_rules.read().unwrap();
    let mut matches = Vec::new();
    let mut matched_buffer = MatchedRulesBuffer::new();
    
    // Evaluate rules level by level
    for level_rules in &rules.rules_by_level {
        for rule in level_rules {
            // Check requires block (if present)
            if let Some(requires) = &rule.requires {
                if !self.evaluate_requires_block(requires, &matched_buffer) {
                    continue; // Skip this rule
                }
            }
            
            // Evaluate condition
            if let Some(condition) = &rule.condition {
                if !self.evaluate_expression(condition, event, &rules.lists) {
                    continue; // Condition not met
                }
            }
            
            // Check correlation (if present)
            if let Some(correlation) = &rule.correlation {
                if !self.check_correlation(correlation, event, &rule.id) {
                    continue; // Correlation not satisfied
                }
            }
            
            // Rule matched!
            let rule_match = RuleMatch {
                rule_id: rule.id.clone(),
                rule_name: rule.name.clone(),
                level: rule.level,
                // ... other fields
            };
            
            matches.push(rule_match.clone());
            matched_buffer.add_match(rule_match);
        }
    }
    
    matches
}

    "src_ip": "192.168.1.100",

    "action": "deny",
    "status": "failed",
    // ... other fields
