│  │ Tokenize │      │ Build   │      │ RuleDefinition│              │

│                                                                      │
│  Input:  RULE TEST WHEN event.vendor == "sophos" THEN...           │

└──────────────────────────────┬──────────────────────────────────────┘
                               │
                               │ Vec<RuleDefinition>
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────────┐
│                   DSL EXECUTOR (dsl_executor.rs)                    │
│                        RULE COMPILATION                             │
│                                                                      │
│  ┌────────────────────────────────────────────────────────────┐    │
│  │  Extract log_types from WHEN clause                        │    │
│  │  "event.vendor == 'sophos' AND event.product == 'xgs'"     │    │
│  │  ────────────────────────────────────────────────────────→ │    │
│  │  log_types = ["sophos:xgs"]                                │    │
│  └────────────────────────────────────────────────────────────┘    │
│                               │                                     │
│                               ▼                                     │
│  ┌────────────────────────────────────────────────────────────┐    │
│  │  Build Indexes (O(1) lookup structures)                    │    │
│  │                                                             │    │
│  │  rules_by_log_type:                                        │    │
│  │    HashMap<String, Vec<CompiledRule>>                      │    │
│  │    ├─ "sophos:xgs" → [RULE1, RULE2, RULE3]                │    │
│  │    ├─ "microsoft:windows" → [RULE4, RULE5]                │    │
│  │    └─ "*" → [RULE_WILDCARD]                               │    │
│  │                                                             │    │
│  │  rules_by_id:                                              │    │
│  │    HashMap<String, CompiledRule>                           │    │
│  │    ├─ "RULE1" → CompiledRule { ... }                       │    │
│  │    └─ "RULE2" → CompiledRule { ... }                       │    │
│  │                                                             │    │
│  │  child_rules:                                              │    │
│  │    HashMap<String, Vec<String>>                            │    │
│  │    ├─ "AUTH_FAIL" → ["AUTH_FAIL_ADMIN", "AUTH_FAIL_EXT"]  │    │
│  │    └─ "AUTH_FAIL_ADMIN" → ["AUTH_FAIL_ADMIN_ROOT"]        │    │
│  │                                                             │    │
│  │  regex_cache:                                              │    │
│  │    HashMap<String, Regex>                                  │    │
│  │    ├─ "/Failed password/" → Regex::new(...).compiled      │    │
│  │    └─ "/sqlmap|nikto/" → Regex::new(...).compiled         │    │
│  └────────────────────────────────────────────────────────────┘    │
│                                                                      │
└──────────────────────────────┬──────────────────────────────────────┘
                               │
                               │ RuleEngine { indexes built }
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────────┐
│                       RUNTIME EVALUATION                            │
│                                                                      │
│  Event arrives from Redis:                                          │
│  ┌──────────────────────────────────────────────────────┐           │
│  │ {                                                    │           │
│  │   "event": {                                         │           │
│  │     "vendor": "sophos",                              │           │
│  │     "product": "xgs",                                │           │
│  │     "action": "deny"                                 │           │
│  │   },                                                 │           │
│  │   "src": { "ip": "192.168.1.50" },                   │           │
│  │   "dst": { "ip": "8.8.8.8", "port": 443 }            │           │
│  │ }                                                    │           │
│  └──────────────────────────────────────────────────────┘           │
│                               │                                     │
│                               ▼                                     │
│  ┌──────────────────────────────────────────────────────┐           │
│  │ 1. Extract log_type                                  │           │
│  │    log_type = "sophos:xgs"                           │           │
│  └──────────────────────────────────────────────────────┘           │
│                               │                                     │
│                               ▼                                     │
│  ┌──────────────────────────────────────────────────────┐           │
│  │ 2. O(1) Rule Lookup                                  │           │
│  │    let rules = rules_by_log_type.get("sophos:xgs")? │           │
│  │    ────────────────────────────────────────────────→ │           │
│  │    [SOPHOS_DENY, SOPHOS_DROP, SOPHOS_SQL_INJ]       │           │
│  └──────────────────────────────────────────────────────┘           │
│                               │                                     │
│                               ▼                                     │
│  ┌──────────────────────────────────────────────────────┐           │
│  │ 3. Evaluate Each Rule (only 3-5 rules)              │           │
│  │                                                      │           │
│  │  for rule in rules {                                │           │
│  │    if eval_expression(rule.when_expr, event) {      │           │
│  │      matches.push(RuleMatch {                       │           │
│  │        rule_id: rule.rule_id,                       │           │
│  │        severity: rule.then_clause.severity,         │           │
│  │        tags: rule.then_clause.tags,                 │           │
│  │      });                                            │           │
│  │                                                      │           │
│  │      // Check for child rules                       │           │
│  │      if let Some(children) = child_rules.get(id) {  │           │
│  │        eval_children(children, event, matches);     │           │
│  │      }                                              │           │
│  │    }                                                │           │
│  │  }                                                  │           │
│  └──────────────────────────────────────────────────────┘           │
│                               │                                     │
│                               ▼                                     │
│  ┌──────────────────────────────────────────────────────┐           │
│  │ 4. Return Matches                                    │           │
│  │    [                                                 │           │
│  │      RuleMatch {                                     │           │
│  │        rule_id: "SOPHOS_DENY",                       │           │
│  │        severity: 4,                                  │           │
│  │        tags: ["firewall", "deny"],                   │           │
│  │        noalert: false                                │           │
│  │      }                                               │           │
│  │    ]                                                 │           │
│  └──────────────────────────────────────────────────────┘           │
│                                                                      │
└──────────────────────────────┬──────────────────────────────────────┘
                               │
                               │ Vec<RuleMatch>
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────────┐
│                        ALERT GENERATION                             │
│  for match in matches {                                             │
│    if !match.noalert {                                              │
│      generate_alert(match.rule_id, match.severity, match.tags);    │
│    }                                                                │
│  }                                                                  │
└─────────────────────────────────────────────────────────────────────┘

## Expression Evaluation Deep Dive

WHEN clause:
event.vendor == "sophos" AND (event.action == "deny" OR bytes > 1000000)

AST:
And(
Eq(
FieldRef { path: ["event", "vendor"] },
Value::String("sophos")
),
Or(
Eq(
FieldRef { path: ["event", "action"] },
Value::String("deny")
),
Gt(
FieldRef { path: ["bytes"] },
Value::Int(1000000)
)
)
)

Evaluation:
┌─────────────────────────────────┐
│ eval_expression(And(...)) │
└────────────┬────────────────────┘
│
├─► eval_expression(Eq(event.vendor, "sophos"))
│ ├─► get_field(["event", "vendor"], event)
│ │ └─► event.get("event")?.get("vendor")? → "sophos"
│ └─► compare("sophos" == "sophos") → TRUE
│
├─► eval_expression(Or(...))
│ ├─► eval_expression(Eq(event.action, "deny"))
│ │ └─► "deny" == "deny" → TRUE
│ └─► TRUE (short-circuit, don't eval right)
│
└─► TRUE AND TRUE → TRUE ✅ MATCH

## Parent-Child Evaluation Flow

Rules:
RULE AUTH_FAIL (parent)
RULE AUTH_FAIL_ADMIN (child of AUTH_FAIL)
RULE AUTH_FAIL_ADMIN_ROOT (child of AUTH_FAIL_ADMIN)

child_rules HashMap:
"AUTH_FAIL" → ["AUTH_FAIL_ADMIN"]
"AUTH_FAIL_ADMIN" → ["AUTH_FAIL_ADMIN_ROOT"]

Event:
{ event: { outcome: "failure" }, user: { name: "root" } }

Evaluation:

  1. Evaluate AUTH_FAIL
    ├─► event.outcome == "failure" → TRUE ✅
    ├─► Generate alert: AUTH_FAIL (severity=4)
    └─► Check child_rules["AUTH_FAIL"] → ["AUTH_FAIL_ADMIN"]
    │
    2. Evaluate AUTH_FAIL_ADMIN
    ├─► user.name IN ["admin", "root"] → TRUE ✅
    ├─► Generate alert: AUTH_FAIL_ADMIN (severity=7)
    └─► Check child_rules["AUTH_FAIL_ADMIN"] → ["AUTH_FAIL_ADMIN_ROOT"]
    │
    3. Evaluate AUTH_FAIL_ADMIN_ROOT
    ├─► user.name == "root" → TRUE ✅
    └─► Generate alert: AUTH_FAIL_ADMIN_ROOT (severity=10)

Result:
[
RuleMatch { rule_id: "AUTH_FAIL", severity: 4 },
RuleMatch { rule_id: "AUTH_FAIL_ADMIN", severity: 7 },
RuleMatch { rule_id: "AUTH_FAIL_ADMIN_ROOT", severity: 10 }
]

## Aggregation Flow (Redis)

Rule:
RULE AUTH_BURST
WHEN
RULE_MATCHED("AUTH_FAIL")
AGGREGATE
count >= 5
within 60s

Events:
Time Event Redis State
──── ───────────────────────── ────────────────────────────────
00s AUTH_FAIL matched agg:AUTH_BURST:client1 = 1 (TTL 60s)
10s AUTH_FAIL matched agg:AUTH_BURST:client1 = 2 (TTL 60s)
20s AUTH_FAIL matched agg:AUTH_BURST:client1 = 3 (TTL 60s)
30s AUTH_FAIL matched agg:AUTH_BURST:client1 = 4 (TTL 60s)
40s AUTH_FAIL matched agg:AUTH_BURST:client1 = 5 (TTL 60s)
──────────────────────────────────
🚨 TRIGGER AUTH_BURST ALERT!

70s (60s elapsed from first) agg:AUTH_BURST:client1 → EXPIRED
75s AUTH_FAIL matched agg:AUTH_BURST:client1 = 1 (TTL 60s)


Redis Commands:

INCR agg:AUTH_BURST:client1
EXPIRE agg:AUTH_BURST:client1 60
GET agg:AUTH_BURST:client1

## Performance Comparison

### Before (O(N×M))

events = [e1, e2, e3, ..., e10000] (10K events/sec)
rules = [r1, r2, r3, ..., r50] (50 rules)

for event in events: # 10,000 iterations
for rule in rules: # 50 iterations
if rule.matches(event): # Total: 500,000 checks/sec ❌
process(event, rule)


### After (O(1))

events = [e1, e2, e3, ..., e10000] (10K events/sec)

for event in events: # 10,000 iterations
log_type = extract_log_type(event) # "sophos:xgs"
rules = index.get(log_type) # O(1) lookup → [r1, r2, r3] (3 rules)

for rule in rules: # Only 3 iterations
if rule.matches(event): # Total: 30,000 checks/sec ✅
process(event, rule)

Improvement: 500K → 30K = 16× reduction

## Memory Layout

RuleEngine {
rules_by_log_type: {
"sophos:xgs" → [Rule1, Rule2, Rule3], ~100 bytes/rule × 3 = 300 bytes
"microsoft:windows" → [Rule4, Rule5], ~100 bytes/rule × 2 = 200 bytes
...
},
rules_by_id: {
"RULE1" → Rule1, ~100 bytes
"RULE2" → Rule2, ~100 bytes
...
},
child_rules: {
"AUTH_FAIL" → ["AUTH_FAIL_ADMIN"], ~24 bytes
...
},
regex_cache: {
"/Failed password/" → Regex::new(...), ~500 bytes/regex
...
}
}

Total: ~50 KB for 50 rules (negligible)
