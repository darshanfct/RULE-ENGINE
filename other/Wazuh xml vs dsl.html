Wazuh xml vs. DSL

This list compiles every available operator, tag, and attribute from the official Wazuh Rule XML Syntax.

I have added the two requested columns:

  1. DSL Equivalent: The syntax for your Rust parser.
  2. Parser/Impl Note: Critical implementation details (e.g., "Requires State Store," "High Memory," "Type Inference").

1. The Core Matchers (Filtering Events)

These tags check if the event matches specific criteria.

XML Operator / Tag Description DSL Equivalent Parser / Implementation Note
<match> Simple sub-string match (faster than regex). contains("text") Optimization: Use Boyer-Moore or memchr in Rust. Case-insensitive by default.
<regex> Wazuh's internal fast regex match. regex(r"\d+") Runtime: Pre-compile these into a RegexSet at startup. Do not compile per-event.
type="pcre2" Attribute enabling Perl-compatible regex (lookarounds). pcre(r"(?<=a)b") Dependency: Requires pcre2 crate. Standard Rust regex crate does not support lookarounds/backreferences.
<field> Matches a specific dynamic field. field["name"] == "val" Access: Must support nested JSON access (e.g., data.aws.region).
<srcip> Matches Source IP or CIDR block. src_ip in 10.0.0.0/8 Type Check: Parser must distinguish IP strings from CIDR strings. Use ipnet crate for logic.
<dstip> Matches Destination IP or CIDR block. dst_ip in 192.168.1.1 Type Check: Same as srcip.
<srcport> Matches Source Port. src_port == 443 Type Inference: Treat as u16 integer for faster comparisons.
<dstport> Matches Destination Port. dst_port == 80 Type Inference: Treat as u16 integer.
<protocol> Matches the protocol (tcp, udp, icmp). protocol == "tcp" Normalization: Ensure input is lower-cased before comparison.
<user> Matches srcuser OR dstuser. user == "admin" Logic: Parser must expand this to src_user == "admin" OR dst_user == "admin".
<url> Matches the request URL. url contains "/login" String: Standard string match.
<id> Matches the decoder event ID (e.g., Win Event ID). event_id == 4625 Type Inference: Treat as u32/u64.
<status> Matches the event status (e.g., "success", "failed"). status == "failed" Field Mapping: Ensure your decoder maps vendor statuses to this standard field.
<hostname> Matches the agent's hostname. agent.name == "web01" Meta Field: Found in the agent metadata, not the log payload.
<program_name> Matches the reporting process (e.g., sshd). program == "sshd" String: Standard match.
<system_name> Matches the system name (rare, usually hostname). system.name == "x" Field Mapping: Verify where your decoders populate this.
<action> Matches the action (allow, deny, drop). action == "drop" String: Standard match.
<data> Matches the generic data field. data contains "error" Warning: The data field can be massive. Parsing this frequently hurts performance.
<extra_data> Matches the extra_data field. extra_data == "x" String: Standard match.
<srcgeoip> Matches Source Country/City. src_geo.country == "US" Dependency: Requires MaxMind/GeoIP DB loaded in memory.**
<dstgeoip> Matches Destination Country/City. dst_geo.city == "Paris" Dependency: Same as above.**
<time> Matches time range (e.g., "6 pm - 7 am"). time between(18:00, 07:00) Logic: Handle ranges crossing midnight (Start > End).
<weekday> Matches day of week (e.g., "weekdays"). day in [mon..fri] Optimization: Use a bitmask (u8) for days to compare in 1 CPU cycle.
<decoded_as> Checks which decoder parsed the event. decoder.name == "json" Meta Field: Checked against the decoder registry.
<category> Checks event category (firewall, ids, etc.). category == "firewall" Tagging: Events need category tags assigned during decoding.
negate="yes" Inverts any tag above. not ... AST: Wraps the condition in a Not(...) node.

2. Logic & Dependencies (The Rule Chain)

These define how rules trigger based on OTHER rules.

XML Operator / Tag Description DSL Equivalent Parser / Implementation Note
<if_sid> Matches if Rule ID X already triggered. caused_by(sid: 100) Execution Order: Requires rules to be evaluated in a DAG or strictly ordered pass.
<if_group> Matches if a rule from Group Y triggered. caused_by(group: "auth") Lookup: Needs efficient lookup of (RuleID -> Groups).
<if_level> Matches if a rule of Level N triggered. caused_by(level >= 10) Comparison: Integer check against previous matches.
<if_matched_sid> Aggregation: Matches if Rule ID X matches in the freq. buffer. trigger if { caused_by(sid: 100) ... } State Store: Look up the "Frequency Table," not just the current event.
<if_matched_group> Aggregation: Matches if Group Y matches in the freq. buffer. trigger if { caused_by(group: "ssh") ... } State Store: Filter Frequency Table by group tag.

3. Aggregation & State (The "Memory")

These require a temporal state store (Redis/Memcached/HashMap).

XML Operator / Tag Description DSL Equivalent Parser / Implementation Note
<frequency> Number of times event must occur. count(5) State: Rule does not fire until counter == 5.
<timeframe> Time window (seconds) for frequency. within(60s) TTL: State entries must expire after 60s.
<same_source_ip> Group count by Source IP. group_by(src_ip) Key Gen: State Key = RuleID + SrcIP.
<same_dstip> Group count by Dest IP. group_by(dst_ip) Key Gen: State Key = RuleID + DstIP.
<same_srcport> Group count by Source Port. group_by(src_port) Key Gen: State Key = RuleID + SrcPort.
<same_dstport> Group count by Dest Port. group_by(dst_port) Key Gen: State Key = RuleID + DstPort.
<same_protocol> Group count by Protocol. group_by(proto) Key Gen: State Key = RuleID + Proto.
<same_action> Group count by Action. group_by(action) Key Gen: State Key = RuleID + Action.
<same_id> Group count by Event ID. group_by(event_id) Key Gen: State Key = RuleID + EventID.
<same_url> Group count by URL. group_by(url) Key Gen: State Key = RuleID + URL (Can be long!).
<same_user> Group count by User. group_by(user) Key Gen: State Key = RuleID + User.
<same_srcuser> Group count by Source User. group_by(src_user) Key Gen: State Key = RuleID + SrcUser.
<same_data> Group count by Data field. group_by(data) Hazard: Keys can be huge. Hash the data before storing as key?
<same_extra_data> Group count by Extra Data. group_by(extra) Hazard: Similar to same_data.
<same_status> Group count by Status. group_by(status) Key Gen: State Key = RuleID + Status.
<same_system_name> Group count by System Name. group_by(sys_name) Key Gen: State Key = RuleID + SysName.
<same_location> Group count by Agent/Location. group_by(agent) Key Gen: State Key = RuleID + AgentID.
<same_field> Group count by Dynamic Field. group_by(field["name"]) Runtime: Extract value of name from JSON, use as key.
<different_srcip> Trigger if N distinct Source IPs seen. unique_count(src_ip) > N Complex State: Store a Set<IP> in value, not just a counter.
<different_dstip> Trigger if N distinct Dest IPs seen. unique_count(dst_ip) > N Complex State: Store a Set<IP>.
<different_srcport> Trigger if N distinct Src Ports seen. unique_count(src_port) > N Complex State: Store Set<u16>.
<different_dstport> Trigger if N distinct Dest Ports seen. unique_count(dst_port) > N Complex State: Store Set<u16> (Port scans).
<different_protocol> Trigger if N distinct Protocols seen. unique_count(proto) > N Complex State: Store Set<String>.
<different_action> Trigger if N distinct Actions seen. unique_count(action) > N Complex State: Store Set<String>.
<different_id> Trigger if N distinct IDs seen. unique_count(id) > N Complex State: Store Set<u32>.
<different_url> Trigger if N distinct URLs seen. unique_count(url) > N Complex State: Store Set<String>. High memory usage.
<different_user> Trigger if N distinct Users seen. unique_count(user) > N Complex State: Store Set<String>.
<different_srcuser> Trigger if N distinct Src Users seen. unique_count(src_user) > N Complex State: Store Set<String>.
<different_data> Trigger if N distinct Data val seen. unique_count(data) > N Hazard: Extremely dangerous for memory usage. Limit set size?
<different_extra_data> Trigger if N distinct Extra Data. unique_count(extra) > N Hazard: Same as above.
<different_status> Trigger if N distinct Statuses seen. unique_count(status) > N Complex State: Store Set<String>.
<different_system_name> Trigger if N distinct Sys Names. unique_count(sys_name) > N Complex State: Store Set<String>.
<different_field> Trigger if N distinct Dynamic Fields. unique_count(field["x"]) > N Complex State: Generic Set storage.
<global_frequency> Count across ALL agents. global_count(N) Dist. Sys: Requires a central Redis/DB shared by all nodes.

4. Database & List Operators

These require loading external .cdb or text files.

XML Operator / Tag Description DSL Equivalent Parser / Implementation Note
<list> Checks if value exists in a CDB list. src_ip in @list_name Symbol Table: Parser must validate @list_name exists.
lookup="match_key" Exact Key Match (Default). val in @list Impl: HashMap::contains_key.
lookup="not_match_key" Key MUST NOT exist. val not in @list Impl: !HashMap::contains_key.
lookup="address_match_key" Match IP against CIDR keys in list. ip in @cidr_list Impl: RadixTree or Trie lookup.
lookup="match_key_value" Match Key, then Regex match Value. lookup(@list, key) =~ r"val" Impl: Fetch value from Map, then run Regex.

5. Rule Options & Actions

These control the output behavior.

XML Operator / Tag Description DSL Equivalent Parser / Implementation Note
<options>no_log Do not write to alerts.json. emit: false Pipeline: Stop processing after match, don't serialize.
<options>no_full_log Strip the raw log payload. emit: partial Pipeline: Remove full_log field before saving.
<options>alert_by_email Force email alert. alert: email Flag: Set email_force = true on alert struct.
<options>no_email_alert Prevent email alert. alert: no_email Flag: Set email_block = true.
<options>log_alert Force log (even if level is low). emit: force Flag: Bypass "Minimum Level" check.
ignore="N" Silence rule for N seconds after firing. cooldown(Ns) State: Set a temporary "Silence Key" in Redis.
overwrite="yes" Replace existing rule with same ID. override: true Loader: When parsing, if ID exists, drop old struct, insert new.
<var> Define a variable for reuse. let $my_var = "..." Parser: Pre-processor step. Replace $my_var in text before parsing.
<info> Arbitrary metadata. meta { info: "..." } Struct: Store in a metadata HashMap.
<description> Human readable text. desc: "..." Struct: String field.
<group> Tags for grouping rules. groups: [a, b] Struct: Vec<String>. Used for if_group logic.
<mitre> Map to MITRE ATT&CK IDs. mitre: ["T1000"] Struct: Vec<String>.
