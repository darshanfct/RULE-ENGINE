# Quickstart Guide

Deploy the Forensic Cybertech agents and server in minutes.

## One-line Installation
```bash
curl -sO https://packages.forensic-cybertech.com/latest/install.sh && sudo bash ./install.sh
```

## Next Steps
1. Wait for the installation to complete.
2. Note the admin credentials printed in the terminal.
3. Navigate to `https://<server-ip>` to access the dashboard.
