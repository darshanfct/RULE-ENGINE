## 📋 **Detailed Design Specifications**

### **1. Kafka Infrastructure**

#### **Topics Design**

```yaml
# Single unified topic for raw logs
logs.raw:
  partitions: 12  # Scale based on throughput
  replication-factor: 3
  retention.ms: 86400000  # 24 hours
  compression.type: snappy
  cleanup.policy: delete
  
  # Partition by tenant_id for:
  # - Ordered processing per tenant
  # - Parallel processing across tenants
  # - Easy tenant isolation

# Single topic for processed logs
logs.processed:
  partitions: 12
  replication-factor: 3
  retention.ms: 3600000  # 1 hour (fast drain to storage)
  compression.type: snappy
```

**Why Single Topics Instead of Per-Tenant?**
- ✅ **Simpler management** - No need to create/delete topics per tenant
- ✅ **Better resource utilization** - Kafka partitions are expensive
- ✅ **Easier monitoring** - Single metric dashboard
- ✅ **Tenant isolation via partition key** - Still logically separated
- ✅ **Scales to thousands of tenants** - No topic limit issues

#### **Tenant-Aware Processing**

Every component maintains tenant context:

1. **Ingestion:** Validate tenant_id, extract client_id
2. **Kafka:** Partition by tenant_id (ordered per tenant)
3. **Processing:** Pass tenant_id through all stages
4. **Rules:** Optional per-tenant rule sets (future)
5. **Storage:** Separate directories per client_id
6. **Metrics:** Label by client_id for monitoring

```rust
use security_rule_engine::{decoder::DecoderEngine, rule_engine::RuleEngine};

struct SyslogProcessor {
    decoder: Arc<DecoderEngine>,
    rule_engine: Arc<RuleEngine>,
    kafka_producer: Arc<KafkaProducer>,
    alert_generator: Arc<AlertIdGenerator>,
}

impl SyslogProcessor {
    async fn process_one(&self, raw_msg: RawLogMessage) -> Result<()> {
        // STEP 1: Parse syslog format
        let parsed = parse_syslog_rfc(&raw_msg.raw)?;
        
        // STEP 2: Decode vendor-specific format
        let normalized = self.decoder.process(&String::from_utf8_lossy(&raw_msg.raw));
        
        // Validate normalization
        if normalized.vendor.is_empty() || normalized.event_type.is_none() {
            warn!("Normalization failed for tenant {}", raw_msg.tenant_id);
            // Still process, but skip rules
            return self.store_without_rules(raw_msg, normalized).await;
        }
        
        // STEP 3: Create event for rule evaluation
        let event = Event {
            tenant_id: raw_msg.tenant_id.clone(),
            timestamp: Utc.timestamp(raw_msg.received_at, 0),
            fields: normalized_to_fields(&normalized),
        };
        
        // STEP 4: Evaluate rules
        let alerts = self.rule_engine.evaluate(&event);
        
        // STEP 5: Generate alert IDs
        let mut alert_ids = Vec::new();
        for alert in &alerts {
            if !alert.no_alert {
                let alert_id = self.alert_generator.generate_alert_id(
                    &raw_msg.client_id,
                    &alert.rule_id,
                    alert.severity as u8,
                ).await?;
                alert_ids.push(alert_id);
            }
        }
        
        // STEP 6: Create processed message
        let processed = ProcessedLogMessage {
            tenant_id: raw_msg.tenant_id.clone(),
            client_id: raw_msg.client_id,
            timestamp: raw_msg.received_at,
            normalized,
            rule_matches: alerts,
            is_alert: !alert_ids.is_empty(),
            alert_ids,
            alert_severity: alerts.iter().map(|a| a.severity as u8).max(),
            raw_log: String::from_utf8_lossy(&raw_msg.raw).to_string(),
        };
        
        // STEP 7: Publish to Kafka
        self.kafka_producer.send(
            "logs.processed",
            &processed.tenant_id,
            &processed
        ).await?;
        
        Ok(())
    }
}

#[tokio::main]
async fn main() -> Result<()> {
    // Initialize components
    let decoder = Arc::new(DecoderEngine::new());
    let rule_engine = Arc::new(RuleEngine::new(load_rules()?)?);
    let kafka_producer = Arc::new(KafkaProducer::new("localhost:9092").await?);
    let alert_gen = Arc::new(AlertIdGenerator::new());
    
    let processor = SyslogProcessor {
        decoder,
        rule_engine,
        kafka_producer,
        alert_generator: alert_gen,
    };
    
    // Create Kafka consumer
    let consumer = KafkaConsumer::new("logs.raw", "syslog-processors").await?;
    
    // Process messages
    loop {
        let messages = consumer.poll(Duration::from_secs(5)).await?;
        
        for msg in messages {
            let raw_msg: RawLogMessage = serde_json::from_slice(msg.payload())?;
            
            if let Err(e) = processor.process_one(raw_msg).await {
                error!("Processing failed: {}", e);
                // Don't commit offset - will retry
                continue;
            }
            
            // Commit offset (message processed successfully)
            consumer.commit(&msg).await?;
        }
    }
}
```

#### **3.3 Storage Worker** (NEW: `src/bin/storage_worker.rs`)

**Purpose:** Consume from `logs.processed` and write to disk

```rust
struct StorageWorker {
    consumer: KafkaConsumer,
    batch: Vec<ProcessedLogMessage>,
    batch_timeout: Duration,
}

impl StorageWorker {
    async fn run(&mut self) -> Result<()> {
        let mut last_flush = Instant::now();
        
        loop {
            // Poll Kafka
            let messages = self.consumer.poll(Duration::from_millis(100)).await?;
            
            for msg in messages {
                let processed: ProcessedLogMessage = serde_json::from_slice(msg.payload())?;
                self.batch.push(processed);
            }
            
            // Flush if batch full or timeout
            if self.batch.len() >= 1000 || last_flush.elapsed() > self.batch_timeout {
                self.flush_batch().await?;
                last_flush = Instant::now();
            }
        }
    }
    
    async fn flush_batch(&mut self) -> Result<()> {
        if self.batch.is_empty() {
            return Ok(());
        }
        
        // Group by client_id and date
        let mut groups: HashMap<(String, String), Vec<ProcessedLogMessage>> = HashMap::new();
        
        for msg in self.batch.drain(..) {
            let date = Utc.timestamp(msg.timestamp, 0).format("%Y-%m-%d").to_string();
            groups.entry((msg.client_id.clone(), date))
                .or_default()
                .push(msg);
        }
        
        // Write each group
        for ((client_id, date), messages) in groups {
            // Write all logs
            let log_path = format!("storage/logs/{}/{}.jsonl", client_id, date);
            self.append_jsonl(&log_path, &messages).await?;
            
            // Write alerts separately
            let alerts: Vec<_> = messages.iter().filter(|m| m.is_alert).collect();
            if !alerts.is_empty() {
                let alert_path = format!("storage/alerts/{}/{}.jsonl", client_id, date);
                self.append_jsonl(&alert_path, &alerts).await?;
            }
        }
        
        Ok(())
    }
    
    async fn append_jsonl<T: Serialize>(&self, path: &str, items: &[T]) -> Result<()> {
        // Create directory if needed
        if let Some(parent) = Path::new(path).parent() {
            tokio::fs::create_dir_all(parent).await?;
        }
        
        // Append to file
        let mut file = tokio::fs::OpenOptions::new()
            .create(true)
            .append(true)
            .open(path)
            .await?;
        
        for item in items {
            let json = serde_json::to_string(item)?;
            file.write_all(json.as_bytes()).await?;
            file.write_all(b"\n").await?;
        }
        
        file.sync_all().await?;
        Ok(())
    }
}
```

- ✅ **More flexible** - Custom rule DSL
- ✅ **Better performance** - Modern architecture
- ✅ **Open source** - No vendor lock-in
